# Sound files (optional)

Every sound in the arena is generated in code. To replace one with a recorded file, save it here as
`<cue>.ogg`, `<cue>.mp3` or `<cue>.wav`, using a cue name from [SOUND.md](../../SOUND.md). Effects can be up to
300 KB and music (`music-battle`, `music-sudden-death`) up to 3 MB. The builds pick the files up automatically;
cues without a file keep their generated sound.
